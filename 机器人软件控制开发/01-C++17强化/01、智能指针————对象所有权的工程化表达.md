
智能指针本质上就是: 用RAII的方式管理堆内存对象, 也就是说, 智能指针不是高级指针语法, 而是C++用来表达对象归谁管, 什么时候释放, 能不能共享的工程工具.


### 核心结论

C++里最重要的问题之一是:
```
这个对象到底归谁所有?
```
智能指针就是用来回答这个问题的.
三个结论:
```
std::unique_ptr<T> // 独占这个对象,负责释放
std::shared_ptr<T> // 多个人共享这个对象,最后一个负责释放
std::weak_ptr<T> // 只观察这个对象,不负责延长它的生命周期
```
现代C++的基本原则是:
```
能用unique_ptr, 就不要用shared_ptr;
能用引用或裸指针表达: 只使用不拥有,就不要乱用shared_ptr;
shared_ptr 要谨慎使用;
weak_ptr 用来打破shared_ptr循环引用.
```
