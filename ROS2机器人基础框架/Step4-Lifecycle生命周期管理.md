### 一、Lifecycle在整个机器人架构中的位置

![[Step4-lifecycle.svg]]
三个模块的职责必须要区分开来

| 模块                | 核心职责              |
| ----------------- | ----------------- |
| System Manager    | 管理整机运行状态          |
| Lifecycle Manager | 协调各业务节点的初始化、激活和停用 |
| Lifecycle Node    | 管理自身资源以及业务逻辑的启停   |
例如机器人开机后, 未来可能需要按照底盘驱动、传感器、定位、导航的依赖关系依次启动. Lifecycle Manager 就负责组织这一个过程, 并在必要模块准备完成后通知整机FSM.
