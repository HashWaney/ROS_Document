**一、建立左驱动轮**
采用双轮差速底盘, 左右轮将使用`continuous`类型的Joint, 使轮子以后可以绕轮轴连续旋转.
![[Pasted image 20261112104004.png]]

本次使用的临时尺寸:

| 参数                  | 示例值     |
| ------------------- | ------- |
| 轮子半径                | 0.05m   |
| 轮子宽度                | 0.04m   |
| 左轮中心X               | 0m      |
| 左轮中心Y               | 0.17m   |
| 左轮中心Z(相对于base_link) | -0.025m |

**二、修改robot.urdf.xacro**
1、 添加轮子尺寸参数
在已有的base_height参数后面添加:
```
<!--驱动轮临时参数-->
<xacro:propert
```
