现在机器人已经具备Visual、Collision和完整的运动学关节结构, 接下来给机器人添加质量(Mass)、质心(Center of Mass)和惯性矩阵(Inertial Tensor), 为后续运动动力学与Gazebo仿真打基础.

一、为什么需要Inertial?
在URDF中, 三个属性的作用不同:

| 属性        | 作用         | 状态   |
| --------- | ---------- | ---- |
| Visual    | 机器人外观      | 已完成  |
| Collision | 碰撞几何       | 已完成  |
| Inertial  | 质量、质心、转动惯量 | 本次配置 |

本次使用的示例质量:

| 部件       | 质量    |
| -------- | ----- |
| 底盘主体     | 8.0kg |
| 左驱动轮     | 0.5kg |
| 右驱动轮     | 0.5kg |
| 辅助万向轮轮体  | 0.2kg |
| 当前建模质量合计 | 9.2kg |

本次按照均匀密度的长方体和实心圆柱体估算惯性矩阵. 将来替换成真实硬件时, 优先通过CAD或实际测量得到质量、质心和惯性参数.
