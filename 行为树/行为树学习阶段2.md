## 目的: 将MoveTo从模拟函数升级成ROS2 Action

这一步的目标是让你的行为树变成真实ROS2架构:

```
Behavior Tree 
|
MoveToAction 节点
|
ROS2 Action Client
|
Fake MoveTo Action Server
```

知识点:

```
1、如何创建自定义的.action 接口
2、如何写Action Server
3、如何在BehaviorTree.CPP节点里写Action Client
4、如何在低电量打断时取消正在执行的Action
```

ROS2 Action 本来就是给“长时间任务” 设计的, 例如导航、机械臂运动、充电对接; 它有goal、feedback、result. 并且支持取消. ROS2 官方文档也明确说明Action适合长任务, 并且相比Service可以持续反馈和取消.

### 一、本阶段完成后的效果

现有的旧逻辑:

```
MoveTo 
	- 打印 moving to A
	- sleep
	- SUCCESS
```

升级后变成:

```
BT MoveToAction:
	- 发送Action Goal: target = A
	- Action Server 模拟移动
	- 每秒反馈progress
	- BT节点持续返回RUNNING
	- 成功后返回SUCCESS
```

低电量时:

```
BatteryLow 变成 SUCCESS
	|
ReactiveFallback 切换分支
	| 
当前 MoveToAction 被halt
	| 
BT 节点发送cancel_goal
	| 
Action Server 收到cancel
	| 
机器人转去Dock
```

### 二、创建Action接口包
ROS2官方建议.msg、.srv、.action这类接口最好单独放在一个interface package中,这样后续C++、Python、Nav2 插件都可以服用.

进入工作空间
```
cd ~/Desktop/ros2_bt_ws/src
```
创建接口包:
```
ros2 pkg create bt_patrol_interfaces \
--build-type ament_cmake \
--license Apache-2.0
```
创建action目录
```
mkdir -p bt_patrol_interfaces/action
```
创建MoveTo.action:
```
string target
---
bool success
string message
---
float32 progress
string current_state
```
.action文件本质上分三段:
```
Goal 
---
Result
---
Feedback
```
这也是ROS2 官方action定义格式.
### 三、配置接口包
编写bt_patrol_interfaces/package.xml
```
<?xml version="1.0"?>
<package format="3">
	<name>bt_patrol_interfaces</name>
	<version>0.0.0</version>
	<description>action interfaces for behavior tree patrol demo</description>
	<maintainer email="hash@example.com">hash</maintainer>
	<license>Apache-2.0</licensen>
	<buildtool_depend>ament_cmake</buildtool_depend>
	<depend>action_msgs</depend>
	<build_depend>rosidl_default_generators</build_depend>
	<exec_depend>rosidl_default_runtime</exec_depend>
	<member_of_group>rosidl_interface_packages</member_of_group>
	<export>
		<build_type>ament_cmake</build_type>
	</export>
</package>
```
编写bt_patrol_interfaces/CMakeLists.txt
```
cmake_minimum_required(VERSION 3.8)
project(bt_patrol_interfaces)

find_package(ament_cmake REQUIRED)
find_package(rosild_default_generators REQUIRED)

rosidl_generate_interfaces(${PROJECT_NAME}
	"action/MoveTo.action"
)

ament_export_dependencies(rosidl_default_runtime)

ament_package()

```
编译接口包:
```
cd ~/ros2_bt_ws
colcon build \
--symlink-install \
--packages-select bt_patrol_interfaces

source install/setup.bash
```
验证接口是否生成成功:
```
ros2 interface show bt_patrol_interfaces/action/MoveTo
```
你应该看到:
```
string target
---
bool success
string message
---
float32 progress
string current_state

```

### 六、写Fake MoveTo Action Server

这个server用来模拟真实机器人运动. 后面进入Nav2时,它会被替换成:
```
/nav2 NavigateToPose Action Server
```
创建文件 fake_move_to_server.cpp
```
#include <memory>
#include <string>
#include <thread>

#include "rclcpp/rclcpp.hpp"
#include "rclcpp_action/rclcpp_action.hpp"

#include "bt_patrol_interfaces/action/move_to.hpp"

class FakeMoveToServer : public rclcpp::Node 
{
public:
	using MoveTo = bt_patrol_interfaces::action::MoveTo;
	using GoalHandleMoveTo = rclcpp_action::ServerGoalHandle<MoveTo>;
	
	FakeMoveToServer()
	: Node("fake_move_to_server")
	{
		using namespace std::placeholders;
		
		action_server_= rclcpp_action::create_server<MoveTo>(
			this,
			"move_to",
			std::bind(&FakeMoveToServer::handle_goal,this,_1,_2),
			std::bind(&FakeMoveToServer::handle_cancel,this,_1),
			std::bind(&FakeMoveToServer::handle_accepted,this,_1)
		);
		RCLCPP_INFO(get_logger(),"Fake MoveTo action server started on /move_to");
	
	}

private: 
	rclcpp_action::Server<MoveTo>::SharedPtr action_server_;
	
	rclcpp_action::GoalResponse handle_goal(
		const rclcpp_action::GoalUUID& uuid,
		std::shared_ptr<const MoveTo::Goal> goal
	)
	{
		(void)uuid;
		
		RCLCPP_INFO(
			get_logger(),
			"Received MoveTo goal: target=%s",
			goal->target.c_str()
		);
	
		return rclcpp_action::GoalResponse::ACCEPT_AND_EXECUTE;
	
	}
	rclcpp_action::CancelResponse handle_cancel(
		const std::shared_ptr<GoalHandleMoveTo> goal_handle
	)
	{
		(void)goal_handle;
		RCLCPP_WARN(get_logger(),"Received cancel request");
		return rclcpp_action::CancelResponse::ACCEPT;
	}
	void handle_accepted(const std::shared_ptr<GoalHandleMoveTo>
	 goal_handle)
	 {
		 std::thread{
		 [this,goal_handle]()
		 {
			 execute(goal_handle);
		 }
		 }.detach();
	
	 }
	void execute(const std::shared_ptr<GoalHandleMoveTo> goal_handle)
	{
		const auto goal = goal_handle->get_goal();
		RCLCPP_INFO(
			get_logger(),
			"Start moving to %s",
			goal->target.c_str()
			
		);
		auto feedback = std::make_shared<MoveTo::Feedback>();
		auto result = std::make_shared<MoveTo::Result>();
		
		rclcpp::Rate loop_rate(2); // 2Hz
		constexpr int total_steps = 20 ;
		for (int i=1; i<=total_steps && rclcpp::ok(); ++i)
		{
			if(goal_handle->is_canceling())
			{
			
				result->success = false;
				result->message = "Canceled while moving to "+goal->target;
				goal_handle->canceled(result);
				
				RCLCPP_WARN(
					get_logger(),
					"MoveTo goal canceled; target=%s",
					goal->target.c_str()
				);
				return;
			}
			feedback->progress = static_cast<float>(i) / static_cast<float>(total_steps);
			feedback->current_state = "Moving to "+goal->target;
			goal_handle->publish_feedback(feedback);
			RCLCPP_INFO(
				get_logger(),
				"Moving to %s, progress=%.2f",
				goal->target.c_str(),
				feedback->progress
			
			);
			
			loop_rate.sleep();
			
		}
		if(rclcpp::ok())
		{
			result->success = true;
			result->message = "Arrived at "+goal->target;
			goal_handle->success(result);
			RCLCPP_INFO(
				get_logger(),
				"MoveTo goal succeeded: target=%s",
				goal->target.c_str()
			
			);
			
		}
	
	}
};
```
